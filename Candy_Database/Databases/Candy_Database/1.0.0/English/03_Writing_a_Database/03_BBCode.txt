[font_size=32][b]BBCode[/b][/font_size]

Pages use Godot's BBCode, the same as a [code]RichTextLabel[/code]. It is not the same as the BBCode of forums: some tags are missing and some are Godot's own. The full list is in Godot's documentation, under [i]BBCode in RichTextLabel[/i].

These are the ones used most:

[font_size=22][b]Lists[/b][/font_size]
[indent][code][lb]ul]
First point
Second point
[lb]/ul][/code][/indent]
[code]ol[/code] makes a numbered list. Each line is one item.


[font_size=22][b]Tables[/b][/font_size]
[indent][code][lb]table=2]
[lb]cell][lb]b]Name[lb]/b][lb]/cell][lb]cell][lb]b]Meaning[lb]/b][lb]/cell]
[lb]cell]Key[lb]/cell][lb]cell]What it is[lb]/cell]
[lb]/table][/code][/indent]
[code]table=2[/code] says how many columns there are. Cells fill the table row by row.


[font_size=22][b]Writing a bracket[/b][/font_size]
A [code][lb][/code] starts a tag. To write one in the text, use [code][lb]lb][/code]. For example, [code][lb]lb]b][/code] shows [lb]b] as plain text.

A tag that is never closed, or closed out of order, shows up as plain text in the page. If something looks wrong, check the tags around it.
