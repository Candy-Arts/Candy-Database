# Candy Database

**Candy Database is a documentation browser for Godot add-ons.**<br>
It provides a convenient way to design and browse add-on documentation, directly in the Godot Editor, with various features:<br>
• Documentation sorted by add-on, version and language.<br>
• Navigation sidebar, with categorizes pages.<br>
• Custom themes per add-on database.<br>
• User-customizable layout and theme overrides.<br>
• Supports BBCode formatting, custom formatting tags, and image embedding.<br>
• Pages can link to other pages.<br>
• Dual page display.<br>
• Search tool.<br>
• Supports mods (custom features).<br>

## Compatibiliy
Candy Database is compatible with Godot 4.2+ (4.2 and above).

## Installation
1. In your Godot project's root folder, create a folder named 'addons' if you don't have one.
2. Place the Candy_Database folder in the 'addons' folder.
3. In Godot editor, enable the Candy Database plugin: Project > Project Settings > Plugins
4. Restart Godot.

Note: if you are using Candy Dialogue Engine, the Candy DE Wizard can download and install Candy Database for you.

## Usage
**Reading**<br>
In the Godot Editor, it adds a new tab at the top named "Candy DB" (where you have 2D, 3D, Script, etc.).
Click the tab to access the database UI.

Note that the tab can be renamed in the Candy Database settings, if you prefer something shorter or more general (DB, Docs, etc.).

**Adding documentation**<br>
1. To view documentation for an add-on, the add-on must provide documentation in Candy Database format.
2. You should download that documentation and place it inside the /addons/Candy_Database/Databases folder.
3. In the Candy DB UI, click the 'Database' menu in the top-left corner, then "Refresh".

**Writing documentation**<br>
See the Candy Database documentation for more information.

Creating a database for your own add-on's documentation can range to very simple to more complex, depending what feature you want to use.
